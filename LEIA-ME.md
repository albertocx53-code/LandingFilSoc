# Landing page independente do Fil&Soc

Esta pasta é um site separado. Não substitua os arquivos do repositório CineFil-Soc com ela.

Para visualizar, abra index.html. Para publicar, crie OUTRO repositório (por exemplo, filsoc-landing), envie o conteúdo desta pasta e importe esse novo repositório como OUTRO projeto na Vercel. Use preset Other, sem comando de build e com diretório de saída na raiz. Não é necessário instalar dependências.

Os botões levam a https://filsoc.vercel.app/. As capas de destaque apontam às páginas de vídeos nesse mesmo site. Para mudar o destino, edite esses endereços em index.html.

Arquivos: index.html, styles.css, capas/ e fonts/. Fontes e imagens incluídas localmente. A página usa HTML e CSS; perguntas frequentes funcionam sem JavaScript.
